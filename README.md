# Secure Multi-Party Question Paper Assembly System (SQPAS)

This is the SQPAS Flask application. It implements role-based access control, AES-256-GCM encryption, secure multi-party assembly, and controlled release of examination papers.

**Deployed URL**: <RENDER_DEPLOYED_URL>

## Application Overview
SQPAS provides a highly secure platform for examination authorities to manage the end-to-end process of question paper creation, assembly, and release.

## User Roles and Demo Accounts
The application uses the following user roles, and you can log into the demo accounts using these usernames:
- **Admin**: `admin`
- **Officer**: `officer`
- **Setter A**: `setter_a`
- **Setter B**: `setter_b`

> [!WARNING]
> The passwords and MFA setup details for these accounts are provided locally in the `.demo_credentials.txt` file (generated by running `seed.py`). These are demo credentials and MUST be changed for real production use. NEVER commit `.demo_credentials.txt` to version control.

## Quickstart

1. **Install dependencies**:
   ```bash
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

2. **Database Setup (Neon PostgreSQL)**:
   This application strictly requires a PostgreSQL database.
   - Create a free database on [Neon](https://neon.tech).
   - Get the connection string.

3. **Configure environment**:
   Copy `.env.example` to `.env`.
   - Fill in `SECRET_KEY` and `ENCRYPTION_KEY`.
   - Paste the Neon connection string as `DATABASE_URL`.
   - **Never commit `.env` to version control.** It contains your database credentials and encryption keys.

4. **Initialize the database (Demo Setup)**:
   To create the necessary database tables and generate demo users, run the seed script:
   ```bash
   python seed.py
   ```
   **Important Security Note**: The `seed.py` script generates secure passwords and fresh MFA secrets for the demo users. It saves these credentials to a local file named `.demo_credentials.txt`.
   - Read this file to get your login details.
   - Use the MFA Secret to set up your Authenticator app.
   - **Delete `.demo_credentials.txt` immediately after securing your access.**

5. **Run the server**:
   ```bash
   python run.py
   ```

## Deployment

### Render Deployment
This application is configured for easy deployment on Render:
- Ensure the Render environment variable `RENDER=true` is set.
- Add your `DATABASE_URL`, `SECRET_KEY`, and `ENCRYPTION_KEY` as secret environment variables.
- The entry point for the production server is: `gunicorn wsgi:app --config gunicorn.conf.py`.

### AWS EC2 Deployment
Please see [AWS_DEPLOYMENT.md](AWS_DEPLOYMENT.md) for detailed instructions on deploying this application safely to AWS EC2 using Gunicorn, Nginx, and PostgreSQL.
